# GLOSSARY — Index des termes d'Aetheria

> Lexique du lore et des systèmes. Les définitions sont originales, inspirées des conventions VRMMO.

## A–Z

| Terme | Définition |
|---|---|
| **Ascension (Shinka)** | Transformation d'une arme en sa forme véritable par un Forgeron Divin. |
| **Capitale de l'Abîme (Ruluath)** | Ville bâtie autour du sceau de la Grande Bleue ; accès réservé aux marqués. |
| **Critique parfait** | Frappe idéale : point vital + timing + élan. Dégâts maximaux. |
| **Éclaireurs** | Nom générique des joueurs : descendants de la flotte stellaire, explorateurs anonymes. |
| **Ère des Divins** | Civilisation disparue dont les reliques parsèment Aetheria. |
| **Entité (Sept Entités)** | Monstres uniques non-respawnables, invincibles hors de leur Scénario Unique EX. |
| **Forge Magique** | Corporation des forgerons (joueurs et PNJ). |
| **Forgeron Divin** | Artisan ultime, capable de forger et d'ascensionner les armes de l'Ère des Divins. |
| **Grande Bleue** | Entité-catastrophe virale qui détruisit les océans ; scellée par Ctharnide. |
| **Inventoriaire** | Dimension séparée remplie d'armes des Divins, obtenue après Vésémon. |
| **Kai (Renforcement)** | Amélioration d'arme en 15 niveaux ; coût explosif après le niveau 10. |
| **Mahni** | Monnaie d'Aetheria. |
| **Mailbird** | Système de messagerie par oiseaux ; gratuit pour les alliés. |
| **Marque** | Malédiction permanente infligée par une Entité (ex. Marque de Lycaon). |
| **Origine** | Choix identitaire à la création (Vagabond, Sang Guidant, Enfant des Bêtes…) ; modifie les interactions avec les PNJ. |
| **PJ (Player Killer)** | Tueur de joueurs ; marqué d'un crâne près du nom. |
| **PNJ autonome** | Personnage non joueur qui mène sa propre vie (routine, relations, objectifs) indépendamment du joueur. |
| **Rabituza** | Royaume caché des Lapins Vorpaux ; zone de Scénario Unique sur invitation. |
| **Reliques des Divins** | Objets technologiques de l'Ère des Divins. |
| **Ruines de Fer de la Divinité** | Chantier antique abritant des unités d'opération magique. |
| **Sainte** | Clerc rare capable de lever certaines Marques. |
| **Scénario Unique EX** | Quête secrète à conditions inconnues ; seule voie pour vaincre une Entité. |
| **Système Mailbird** | Voir Mailbird. |
| **Vestiges** | Nom générique des ruines des Divins. |
| **VIT** | Vitalité ; certains équipements exigent un seuil de VIT pour être portés. |
| **Voie** | Métier de combat du personnage (Chevalier, Mercenaire, Moine, Voleur→Ninja…). |
| **12 Terres** | Les douze régions du continent, de Priméa à Cinquantia. |

## Conventions d'écriture

- Les noms japonais d'origine (Lycagon, Vésémon, Ctharnide…) sont des **transpositions de travail** — à remplacer définitivement par les noms Aetheria finaux avant publication du jeu.
- Ne pas utiliser de termes du monde réel (pseudo, login, patch) dans le lore en jeu — sauf pour les coulisses (cette doc).
- Les chiffres de système (15 niveaux de Kai, seuil VIT 400) sont des valeurs de design à ajuster lors de l'implémentation.
